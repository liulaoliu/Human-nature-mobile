## 4. W4：`_runOne` 不核对模型回的词

**位置**：`I:\Examples\dlaoshi_app\lib\viewmodels\ai_batch_view_model.dart:220-252` 的 `Future<AiReply?> _runOne(AiJob job)`。

**现在**：`parseAnalysis(reply.text).words` 全量 `applyWordAnalysis` 落库（`:242-243`），模型多回/拼错一个词，词库会凭空多一条。

**改成**：落库前按本块请求过滤（`job.words` 是 trim 后的原词，`WordAnalysis.word` 小写比对）：

```dart
final requested = job.words.map((w) => w.trim().toLowerCase()).toSet();
final words = parsed.words
    .where((wa) => requested.contains(wa.word.trim().toLowerCase()))
    .toList(growable: false);
if (words.isEmpty) {
  _failedIds[job.id] = '模型没给回本块请求的词';
  return null; // 与现有失败分支同路：留待办、跳出本轮
}
```

落库用 `words` 而不是 `parsed.words`（若想提示被丢掉的词数，可 `_notice` 里补一句，非必须）。

**配套测试**：`ai_batch_view_model_test.dart` 加 2 例：
- fake 回复表格含本块请求之外的一行（如 `banana | ...`）→ 跑完后 `repo.load()` 的 items 里**没有** `banana`，且本块照常 done；
- fake 回复只回请求之外的词 → `failedCount == 1`、词库零变化。
